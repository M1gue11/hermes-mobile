# Segurança

O Hermes Mobile é um cliente experimental que pode acessar dados e credenciais
de uma instalação Hermes configurada por quem o utiliza. Não o considere
adequado para ambientes críticos sem uma avaliação própria.

## Reportar uma vulnerabilidade

Não publique detalhes exploráveis em issues públicas. Use o mecanismo privado
de reporte de vulnerabilidades oferecido pela plataforma de hospedagem deste
repositório. Se esse mecanismo não estiver disponível, peça aos mantenedores um
canal privado antes de enviar detalhes técnicos. Não há endereço de e-mail de
segurança dedicado neste momento.

Inclua uma descrição, impacto provável, passos mínimos para reproduzir e uma
mitigação possível. Remova tokens, cookies, tickets, chaves, dados pessoais e
identificadores de instalações dos materiais enviados.

O projeto não oferece SLA de resposta nem política de versões suportadas. A
correção e divulgação coordenada serão avaliadas pelos mantenedores caso a caso.
